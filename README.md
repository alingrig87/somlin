# Somlin - Aplicație Demo pentru Somnolog

Aplicație demo pentru gestionarea și analiza datelor de somn, dezvoltată pentru colaborare cu un somnolog în vederea creării unei aplicații complexe.

## 📚 Documentație

- **[ARCHITECTURE.md](./ARCHITECTURE.md)** - Arhitectură detaliată și system design pentru aplicația complexă
- **[TECH_STACK.md](./TECH_STACK.md)** - Recomandări tehnologii și stack tehnologic
- **[DEMO_ROADMAP.md](./DEMO_ROADMAP.md)** - Roadmap și plan de dezvoltare pentru demo

## 🎯 Obiectiv

Crearea unei aplicații demo care să demonstreze conceptul și funcționalitățile de bază pentru:
- Înregistrarea datelor de somn
- Vizualizarea și analiza pattern-urilor de somn
- Generarea de rapoarte pentru somnologi
- Colaborarea cu somnologul pentru dezvoltarea aplicației complexe

## 🚀 Tehnologii Recomandate (Demo)

### Frontend
- **Next.js 14** - React framework cu App Router
- **TypeScript** - Type safety
- **Tailwind CSS** - Styling modern
- **shadcn/ui** - Componente UI
- **Recharts** - Vizualizări grafice

### Backend
- **FastAPI** - Python web framework rapid
- **PostgreSQL** - Baza de date relațională
- **SQLAlchemy** - ORM
- **JWT** - Autentificare

### DevOps
- **Docker + Docker Compose** - Containerizare pentru development

## 📋 Funcționalități Demo

- ✅ Autentificare (pacienți și doctori)
- ✅ Înregistrare date somn (manual)
- ✅ Dashboard cu statistici și grafice
- ✅ Rapoarte PDF și export CSV
- ✅ Vizualizare evoluție somn
